# Current configuration

The recommended configuration for new installations is:

**[WinNative-Cocoon-AUTO-RETURN-v5.json](WinNative-Cocoon-AUTO-RETURN-v5.json)**

This is the current Cocoon custom-platform/player JSON. It adds the **WinNative Standard (Cocoon return)** player and the tested return-to-Cocoon behaviour.

For a new installation, use the download attached to the latest release:
https://github.com/themastertiger123-hue/WinNative-Cocoon-Integration/releases/latest

Do not use older files from the archive for a fresh setup.
