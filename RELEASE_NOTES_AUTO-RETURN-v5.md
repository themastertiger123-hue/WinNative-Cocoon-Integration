# WinNative × Cocoon — AUTO-RETURN v5

## What's new

- Return directly to Cocoon when ending the WinNative session from the side menu using **Exit**.
- Launch intent now includes ACTION_VIEW, the winnative://com.winnative.cmod/shortcut URI, and the launched_from_pinned_shortcut=true extra.
- Custom player has a distinct identifier from the regular WinNative Standard player.

## Installation

1. Import Windows-WinNative-Cocoon-AUTO-RETURN-v5.json in Cocoon under Settings → Library & Data → Platforms → Custom Platform.
2. Set Default player to WinNative Standard (Cocoon return).
3. Launch games from Cocoon.
4. To return to Cocoon, choose Exit from WinNative's side menu.

## Verification

The project creator has confirmed that the return-to-Cocoon flow works on their Android device.

This is an unofficial community configuration. Compatibility may vary across devices, Cocoon releases and WinNative builds.
